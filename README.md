An entry for make.fun's ["One Word, First Thought"](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8) bounty: send exactly one word, the first that comes to mind, and let a judge compare words two at a time on which is more interesting.

This program writes a single word — **quiver** — to `entry.txt`. Quiver is surprising rather than the safe expected word, vivid (a trembling, and the case that holds arrows), and carries a double meaning that rewards a second look: a tremble and a quiver of arrows in six letters.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` containing the word `quiver`.
